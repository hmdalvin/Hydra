# Usage Guide for Hydra Video Converter

This guide explains how to use Hydra Video Converter for converting videos using FFmpeg.

## Running the Application

### Windows

Run the following command in the terminal:

```sh
./build/hydra_video_converter.exe
```

Or double-click the executable file in the `build` folder.

### Linux/macOS

Run the application using:

```sh
./build/hydra_video_converter
```

## Converting a Video

1. **Open the application** and select the video file you want to convert.
2. **Choose the output format** (MP4, MKV, AVI, MOV, etc.).
3. **Set optional parameters** such as resolution, bitrate, and frame rate.
4. **Click the Convert button** to start the process.
5. The converted file will be saved in the output directory.

## Batch Conversion

To convert multiple videos at once:

1. Select multiple files or import a CSV list.
2. Configure the conversion settings.
3. Start the batch process and monitor the progress.

## Customizing FFmpeg Settings

Advanced users can specify custom FFmpeg arguments in the settings menu.

## Troubleshooting

- Ensure **FFmpeg** is installed and properly configured.
- Check if the **output format is supported** by your device.
- If errors occur, consult the application logs for details.
